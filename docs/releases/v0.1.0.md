# Qrecs v0.1.0

## English

Qrecs v0.1.0 is the first public MVP release for macOS 15 and later.

> **Pre-release:** the GitHub ZIP is ad-hoc signed and unnotarized. It is intended for early testing, not general distribution. macOS may require Finder → right-click/Control-click **Open** on first launch. Do not disable or bypass Gatekeeper.

### Highlights

- Native SwiftUI Quran recitation library with 172 cataloged reciters and 114 surahs.
- Streaming playback, favorites, search/sort, queue navigation, and manual offline downloads.
- Four independently mixable CC0 ambient sounds.
- English/Russian localization, appearance controls, offline filtering, and cache management.
- Bundled read-only GRDB/SQLite catalog with separate persistent user data.

### Install and verify

Download `Qrecs-0.1.0-macOS.zip` and `Qrecs-0.1.0-macOS.zip.sha256` from this release, then run:

```sh
shasum -a 256 -c Qrecs-0.1.0-macOS.zip.sha256
```

Extract the ZIP, move `Qrecs.app` to Applications, and use Finder's **Open** command if macOS presents the unnotarized-app warning.

### Known limitations

- The build is not Developer ID signed or notarized and has no automatic updater.
- Quran audio is streamed from third-party hosts; availability, performance, URLs, and terms can change independently of Qrecs.
- Offline downloads are manually managed and can consume significant disk space; there is no automatic quota or eviction.
- The interface is localized only in English and Russian.
- This MVP has no in-app source-rights registry or per-recording license display.

## Русский

Qrecs v0.1.0 — первый публичный MVP-выпуск для macOS 15 и новее.

> **Предварительный выпуск:** ZIP-файл на GitHub подписан ad-hoc и не нотаризован. Он предназначен для раннего тестирования, а не массового распространения. При первом запуске macOS может потребовать выбрать в Finder правой кнопкой мыши/Control-кликом команду **Открыть**. Не отключайте и не обходите Gatekeeper.

### Главное

- Нативная SwiftUI-медиатека чтений Корана: 172 чтеца и 114 сур в каталоге.
- Потоковое воспроизведение, избранное, поиск/сортировка, навигация по очереди и ручные офлайн-загрузки.
- Четыре независимо настраиваемых фоновых звука CC0.
- Русская/английская локализация, настройки оформления, офлайн-фильтрация и управление кэшем.
- Встроенный каталог GRDB/SQLite только для чтения и отдельное постоянное хранилище пользователя.

### Установка и проверка

Скачайте из выпуска `Qrecs-0.1.0-macOS.zip` и `Qrecs-0.1.0-macOS.zip.sha256`, затем выполните:

```sh
shasum -a 256 -c Qrecs-0.1.0-macOS.zip.sha256
```

Распакуйте ZIP, переместите `Qrecs.app` в «Программы» и используйте команду Finder **Открыть**, если macOS покажет предупреждение о ненотаризованном приложении.

### Известные ограничения

- Сборка не подписана сертификатом Developer ID, не нотаризована и не содержит механизма автоматического обновления.
- Аудио Корана поступает со сторонних хостингов; доступность, скорость, URL и условия могут меняться независимо от Qrecs.
- Офлайн-загрузки управляются вручную и могут занимать значительное место; автоматической квоты и очистки нет.
- Интерфейс локализован только на русский и английский языки.
- В MVP нет встроенного реестра прав источников или отображения лицензии каждой записи.
