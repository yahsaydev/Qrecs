# Qrecs v0.1.2

[English version](v0.1.2.md) · [README](../../README.ru.md)

Qrecs v0.1.2 — это предварительная версия для macOS 15 и новее, сосредоточенная на эргономике плеера, расширении каталога и разнообразии фоновых звуков.

> **Важно:** приложение имеет ad-hoc подпись и не нотариализовано. Оно предназначено для раннего тестирования. При первом запуске может потребоваться нажать правой кнопкой мыши на `Qrecs.app` в Finder и выбрать **Открыть**.

## Основные изменения

- **Компактный мини-плеер:** Высота плеера уменьшена до 54pt, оптимизированы отступы для более аккуратного вида.
- **Новый чтец:** В каталог добавлен Мухаммад Хишам (ID 10) с 23 подтвержденными сурами.
- **Фоновые звуки:** В микшер добавлен звук «Ночь» (сверчки). Ресурс распространяется по лицензии CC0 1.0 Universal (автор: Solar01).
- **Пайплайн каталога:** Улучшены инструменты сборки для поддержки новых снимков данных и воспроизводимой генерации базы данных.
- **Чистота репозитория:** Обновлен `.gitignore` и удалены служебные файлы агентов из системы контроля версий.

## Установка и проверка

Скачайте `Qrecs-0.1.2-macOS.zip` и `Qrecs-0.1.2-macOS.zip.sha256`, затем выполните:

```sh
shasum -a 256 -c Qrecs-0.1.2-macOS.zip.sha256
```

Распакуйте архив, переместите `Qrecs.app` в Программы и используйте команду **Открыть** в Finder, если macOS выдаст предупреждение.

## Известные ограничения

- Сборка не подписана Developer ID и не имеет автообновления.
- Аудио сур стримится со сторонних хостов; доступность и ссылки могут меняться независимо от приложения.
- Загрузки для офлайн-режима управляются вручную и могут занимать значительное место на диске.
- Интерфейс локализован только на английский и русский языки.
