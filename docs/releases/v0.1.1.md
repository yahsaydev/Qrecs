# Qrecs v0.1.1

[Русская версия](v0.1.1.ru.md) · [README](../../README.md)

Qrecs v0.1.1 is a pre-release for macOS 15 and later focused on catalog quality, playback presentation, and release branding.

> **Important:** the downloadable app is ad-hoc signed and unnotarized. It is intended for early testing, not general distribution. macOS may require Finder → right-click/Control-click **Open** on first launch. Do not disable or bypass Gatekeeper.

## Highlights

- A complete Qrecs icon set for macOS and updated in-app/release version metadata.
- Native SwiftUI library navigation with favorites, search, sortable surahs, queue playback, and manual offline downloads.
- Refined mini-player presentation with playback motion and equalizer feedback.
- Four independently mixable, gapless-looped CC0 ambient sounds.
- English/Russian localization, appearance controls, offline filtering, and cache management.
- Deterministic build-time support for audited, confirmed SurahQuran snapshots, including reciters whose published surah sets are sparse.
- A bundled read-only catalog: release contents are fixed at build time, and runtime catalog crawling is not performed.

## Install and verify

Download `Qrecs-0.1.1-macOS.zip` and `Qrecs-0.1.1-macOS.zip.sha256`, then run:

```sh
shasum -a 256 -c Qrecs-0.1.1-macOS.zip.sha256
```

Extract the ZIP, move `Qrecs.app` to Applications, and use Finder's **Open** command if macOS presents the unnotarized-app warning.

## Known limitations

- The build is not Developer ID signed or notarized and has no automatic updater.
- Quran audio is streamed from third-party hosts; availability, performance, URLs, and terms can change independently of Qrecs.
- A sparse catalog entry exposes only published and audited surahs, so some reciters do not have all 114 tracks.
- Offline downloads are manually managed and can consume significant disk space; there is no automatic quota or eviction.
- The interface is localized only in English and Russian.
- Qrecs does not include an in-app source-rights registry or per-recording license display.
