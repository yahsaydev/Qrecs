# Qrecs v0.1.2

[Русская версия](v0.1.2.ru.md) · [README](../../README.md)

Qrecs v0.1.2 is a pre-release for macOS 15 and later focused on player ergonomics, expanded catalog, and ambient audio variety.

> **Important:** the downloadable app is ad-hoc signed and unnotarized. It is intended for early testing, not general distribution. macOS may require Finder → right-click/Control-click **Open** on first launch. Do not disable or bypass Gatekeeper.

## Highlights

- **Compact Mini-Player:** Reduced player height to 54pt and optimized layout padding for a more integrated, less obstructive appearance.
- **New Reciter:** Muhammad Hisham (ID 10) added to the catalog with 23 confirmed surahs.
- **Ambient Audio:** Added "Night" (cricket ambience) to the mixer. This resource is CC0 1.0 Universal audio by Solar01.
- **Catalog Pipeline:** Hardened build-time tooling to support additive aliased snapshots and reproducible database generation.
- **Repository Standards:** Standardized `.gitignore` and removed local agent artifacts from version control.

## Install and verify

Download `Qrecs-0.1.2-macOS.zip` and `Qrecs-0.1.2-macOS.zip.sha256`, then run:

```sh
shasum -a 256 -c Qrecs-0.1.2-macOS.zip.sha256
```

Extract the ZIP, move `Qrecs.app` to Applications, and use Finder's **Open** command if macOS presents the unnotarized-app warning.

## Known limitations

- The build is not Developer ID signed or notarized and has no automatic updater.
- Quran audio is streamed from third-party hosts; availability, performance, URLs, and terms can change independently of Qrecs.
- Offline downloads are manually managed and can consume significant disk space; there is no automatic quota or eviction.
- The interface is localized only in English and Russian.
