Qrecs создан на SwiftUI, AVFoundation и GRDB для macOS 15 и новее.

## Возможности

- Нативная медиатека с избранными чтецами, поиском и сортируемыми таблицами сур.
- Потоковое воспроизведение, очередь по номерам сур и глобальный мини-плеер.
- Загрузка выбранных записей, явный офлайн-режим и очистка хранилища по чтецу или целиком.
- Четыре независимо настраиваемых зацикленных фоновых звука: огонь, птицы, дождь и водопад.
- Русская и английская локализации, режимы оформления Системный/Светлый/Тёмный и системный Liquid Glass там, где он поддерживается.
- Встроенный каталог SQLite только для чтения. Обычная сборка, тесты и запуск приложения не обходят сайты и не загружают метаданные каталога.
- Детерминированные инструменты сборки могут явно подключить заранее проверенный и подтверждённый снимок SurahQuran. Для чтецов с неполным набором публикаций сохраняются только действительно доступные суры; отсутствующие дорожки не создаются.

## Установка v0.1.1

> **Предупреждение о предварительном выпуске:** `Qrecs-0.1.1-macOS.zip` подписан ad-hoc и не нотаризован. Сборка предназначена для раннего тестирования, а не массового распространения.

Скачайте ZIP и файл `.sha256` со страницы [выпуска v0.1.1](docs/releases/v0.1.1.ru.md), затем проверьте архив:

```sh
shasum -a 256 -c Qrecs-0.1.1-macOS.zip.sha256
```

Распакуйте ZIP и переместите `Qrecs.app` в «Программы». При первом запуске macOS может заблокировать ненотаризованное приложение. В Finder нажмите правой кнопкой мыши (или Control-кликом) на `Qrecs.app`, выберите **Открыть**, затем подтвердите **Открыть**. Не отключайте и не обходите Gatekeeper.

## Сборка и тесты

Требуются macOS 15 или новее, совместимая версия Xcode и инструменты командной строки Xcode.

```sh
# Отладочная сборка и запуск
./script/build_and_run.sh

# Сборка приложения и обоих тестовых раннеров
xcodebuild build-for-testing -project Qrecs.xcodeproj -scheme Qrecs \
  -destination 'platform=macOS'

# Полный план тестов
xcodebuild test -project Qrecs.xcodeproj -scheme Qrecs \
  -destination 'platform=macOS'

# Проверка детерминированного каталога и снимков
python3 -m unittest discover -s CatalogTools/Tests -v

# Регрессионные проверки выпуска
bash script/tests/release_branding_tests.sh
bash script/tests/package_release_tests.sh
```

Создание детерминированного ad-hoc подписанного Release ZIP и SHA-256-файла в `dist/`:

```sh
./script/package_release.sh
```

Скрипт использует версии зависимостей из `Package.resolved`, собирает универсальное Release-приложение, проверяет версию и значок, удаляет тестовые и отладочные артефакты, выполняет ad-hoc подпись с рабочими entitlements, проверяет подпись и нормализует время файлов в архиве.

## Каталог и данные пользователя

Исходные данные находятся в `CatalogTools/Data/`, а создаваемая база приложения — в `Qrecs/Resources/Catalog/catalog.sqlite`. Размер каталога намеренно не продублирован в документации; при подготовке выпуска проверяйте точную встроенную базу:

```sh
sqlite3 Qrecs/Resources/Catalog/catalog.sqlite \
  'select key, value from catalog_meta where key in ("reciter_count", "surah_count", "track_count") order by key;'
```

Пересборка по данным репозитория с необязательным подключением полностью проверенного снимка и полного аудита прежних аудиоссылок. Команды обхода и аудита описаны в [руководстве по каталогу](CatalogTools/README.md):

```sh
python3 CatalogTools/build_catalog.py
python3 CatalogTools/build_catalog.py \
  --snapshot /path/to/confirmed-surahquran-snapshot.json \
  --snapshot-aliases CatalogTools/Data/surahquran_aliases.json \
  --snapshot-localizations CatalogTools/Data/surahquran_localizations.json \
  --legacy-audit /path/to/legacy-audit.json
```

Из-за песочницы изменяемые данные Qrecs хранятся в `~/Library/Containers/com.heezya.Qrecs/Data/Library/Application Support/Qrecs/`:

- `UserData/user.sqlite` содержит избранное и метаданные завершённых загрузок.
- `AudioCache/` содержит записи Корана, явно загруженные пользователем.

Офлайн-аудио не удаляется автоматически. В Настройках можно удалить загрузки отдельного чтеца или очистить всё аудиохранилище.
